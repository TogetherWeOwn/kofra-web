# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub:
[report a vulnerability](https://github.com/TogetherWeOwn/kofra-web/security/advisories/new). Do not open
a public issue.

Include what you found, how to reproduce it and the impact you expect. We aim to acknowledge reports
within three working days.

## Supported versions

Only the current `main` branch is supported. Nothing from this repository is deployed yet.
